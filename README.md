# Learning SharedPreferences

Continuation of [LearningFlutter](https://github.com/torressg/LearningFlutter), from the Santander Bootcamp 2023. This version adds local storage with `shared_preferences`.

## What's covered

- A settings page that saves user name, email and notification preferences on the device and loads them back
- Everything from the previous project: navigation, forms, cards, list views, image assets and simple services

## Stack

Flutter · Dart · shared_preferences

## Running

```bash
flutter pub get
flutter run
```
